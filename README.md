# File Bridge

在浏览器之间传送文字和文件的轻量工具。支持同网络设备发现、数字配对、WebRTC 文件直传、传输进度及刷新后恢复会话，无需安装客户端。

> 入口使用图片验证码进行人机验证，**不是私密密码或用户身份验证**。任何能够识别验证码的人都可以进入。需要限制访问人员时，请另外配置身份验证。

## 功能

- **图片验证码**：随机 4 位数字，点击刷新，5 分钟有效，每次提交后失效。
- **登录限速**：同一 IP 连续输错 3 次锁定 1 小时，刷新图片和重启服务不能清除锁定。
- **设备发现**：列出同网络内已登录、尚未配对的设备，点击即可免码连接。
- **数字配对**：两台设备也可以通过 4 位数字配对码建立一对一会话。
- **配对限速**：同一客户端地址每分钟最多尝试 8 次配对码，超过后短暂拒绝，避免 4 位码被枚举。
- **文字传输**：实时发送文字，接收到的消息支持图标按钮一键复制。
- **文件直传**：优先通过 WebRTC 在设备之间发送文件，无法直传时通过服务器分块转发。
- **多选与文件夹**：加号一次可选多个文件；也可选择或拖入整个文件夹，文件夹会自动打包为 ZIP（仅存储、不压缩）发送，接收方解压后保留目录结构。
- **拖拽发送**：把文件或文件夹拖到聊天窗口即可加入发送队列；拖入纯文字则填入输入框。
- **实际进度**：显示对方已接收的字节数、百分比和平均速度，支持取消。
- **会话恢复**：同一标签页刷新或短暂断网后自动恢复配对，重新建立直传。
- **移动端布局**：适配安全区域及键盘引起的可见视口高度、偏移变化。

## 快速开始

环境要求：Node.js 18 或更高版本、npm。

```bash
npm ci
npm start
```

打开 `http://localhost:5000`。局域网内其他设备可使用服务器的局域网 IP 和端口访问，推荐部署 HTTPS 以获得更一致的浏览器行为。

```bash
npm run dev  # 修改代码后自动重启
npm test     # 自动化测试
npm run icons  # 重新生成标签图标（修改 favicon.svg 后）
```

## 使用方法

1. 两台设备打开网站，输入右侧图片中的数字进入。
2. 在“同网络在线设备”中核对对方的设备名称，点击连接；或一台生成数字配对码，另一台输入。
3. 输入文字发送；通过加号一次选择多个文件，通过文件夹按钮选择文件夹，或直接把文件 / 文件夹拖进聊天窗口。选中的文件可在发送前逐个移除，点击“发送”后按顺序逐个传输。
4. 查看传输方式：显示“设备直传 · 不经过服务器”表示文件走浏览器之间的通道；显示“服务器转发”表示经 Node 服务转发。
5. 点击“退出”离开当前配对；点击“锁定”退出网站登录。

### 设备发现与直传的区别

局域网直接部署时，按服务器网卡的实际网段发现设备；公网部署时，按相同出口 IP 发现候选设备。共享出口 IP 不一定代表同一局域网，因此要核对设备名称。

发现设备不代表直传已经成功。WebRTC 默认使用本地主机候选（浏览器会把内网地址隐藏为 mDNS 的 `.local` 名称），并默认向 `STUN_URLS` 查询服务器反射候选；可通过环境变量配置 STUN，网络完全禁止点对点 UDP 时也可配置 TURN。代理、VPN / TUN 虚拟网卡、不同网段或 Wi-Fi 客户端隔离仍可能阻止直传，此时回退到服务器转发。文字始终经过服务器。

若长时间停留在“正在建立直传…”后回退，状态栏会显示收集到的候选类型（host/srflx/relay），浏览器控制台另有 ICE 诊断日志。同一局域网内直传失败最常见的原因是设备开启了代理 / VPN 的 TUN 模式，需要把本地网段加入“直连 / 绕过代理”规则；iOS 还需确认 Safari 已获得“本地网络”权限。

### 文件限制

- 设备直传单文件上限：**1 GiB**。
- 服务器转发单文件上限：默认 **20 MiB**，可通过 `MAX_FILE_SIZE` 修改。
- 直传采用 256 KiB 数据块、最多 16 块（约 4 MiB）在途并预读下一块，以 SCTP 发送缓冲区（约 4 MiB 高水位）作为背压，避免每块往返限制吞吐；单条消息最多 16 KiB，并按浏览器协商上限缩小。进度约每 200 ms 更新，完成状态仍以接收端确认完整文件为准。
- 发送端分块读取，接收端仍在浏览器内存中组装文件后提供下载。手机接收大文件可能受到内存限制，请保持页面在前台。
- 文件夹在发送端浏览器内打包为 ZIP 后按单文件上限发送，全程不写入服务器磁盘；超过单文件上限的文件夹会跳过并提示。拖拽或多选的散装文件逐个发送。
- 文件不会写入服务器磁盘；接收端确认完整接收后才显示发送完成。
- 刷新页面不会保存聊天记录、下载链接或传输中的文件，未完成的文件需重新发送。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `5001` | 服务监听端口，绑定 `0.0.0.0` |
| `HOST` | `0.0.0.0` | 服务监听主机，也用于启动日志中的访问地址 |
| `MAX_FILE_SIZE` | `20971520` | 服务器转发文件上限，单位字节 |
| `ROOM_TTL_MS` | `1800000` | 数字配对码首次加入的有效期；断线设备的位置保留时间，单位毫秒 |
| `SESSION_TTL_MS` | `86400000` | 登录会话有效期，单位毫秒 |
| `AUTH_STATE_DIR` | 项目内 `.data` | 失败次数、锁定时间的持久化目录 |
| `TRUST_PROXY` | `loopback` | 信任的反向代理 IP/CIDR，多个用逗号分隔 |
| `STUN_URLS` | `stun:stun.l.google.com:19302` | 下发给浏览器的 STUN 地址，多个用逗号分隔；设为空可禁用 |
| `TURN_URL` | 未设置 | 可选的 TURN 地址（逗号分隔），用于点对点 UDP 被完全阻断的网络 |
| `TURN_USERNAME` | 未设置 | TURN 用户名 |
| `TURN_CREDENTIAL` | 未设置 | TURN 密码 |
| `NODE_ENV` | 未设置 | 设为 `production` 时静态资源缓存 1 小时 |

例如，配对码及断线位置保留 30 分钟，登录有效期为 24 小时：

```bash
ROOM_TTL_MS=1800000 SESSION_TTL_MS=86400000 npm start
```

项目没有自动加载 `.env` 文件；请通过命令行、进程管理器或宝塔项目环境变量设置，修改后重启 Node 服务。

### 会话有效期

- `ROOM_TTL_MS` 的断线保留时间从每台设备断开时计算；在线会话不会因该时间自动断开。
- 恢复凭证保存在标签页的 `sessionStorage`，并绑定登录会话。主动退出会释放位置；丢失凭证或登录失效后需重新配对。
- 服务端登录有效期按最后校验时间计算，浏览器 Cookie 的有效期则从登录时固定计时，不自动续期。
- 服务重启会清除登录会话、配对和图片验证码，但保留磁盘中的登录锁定记录。


代理位于其他主机或容器时，将 `TRUST_PROXY` 设置为实际代理地址，且由代理正确设置客户端地址头，不要信任任意来源。这影响设备发现和按 IP 锁定的准确性。

更新时同步全部源码及依赖锁文件，执行 `npm ci --omit=dev` 并重启，两端刷新页面。重启后需重新登录和配对。

## 登录与数据说明

- 登录成功后使用随机会话令牌和 HttpOnly、SameSite Cookie；Socket.IO 同样校验登录状态。
- 同一出口 IP 的设备共用错误次数和锁定；成功登录清零错误次数。锁定期间不能新登录，已登录会话保持有效。
- `.data/login-attempts.json` 保存失败次数和锁定时间，不保存验证码；已被 `.gitignore` 排除。
- 所有响应带 CSP（脚本 / 样式仅允许同源），HTTPS 下附加 HSTS。登录页的样式与脚本为独立静态文件，在登录中间件之前放行，其余静态资源均需登录。
- 当前采用单 Node 进程内存管理配对和会话，不支持直接横向扩展为多实例；多实例需要共享存储及 Socket.IO 适配。

## 项目结构

```text
server.js               HTTP、登录接口、配对、恢复、信令和转发
login-guard.js          图片验证码和持久化登录锁定
discovery.js            网络分组及设备名称
public/index.html      配对与聊天页面
public/login.html      验证码登录页面
public/app.js           消息、进度、复制、拖拽及移动端视口逻辑
public/transfer.js      WebRTC 直传与服务器分块转发（直传 / 转发双上限）
public/zip.js           文件夹 ZIP 打包（仅存储，流式 CRC）
public/style.css       聊天与配对页样式
public/login.css       登录页样式
public/login.js        登录页验证码与提交逻辑
public/favicon.svg     浏览器标签图标（矢量源）
public/favicon.ico     标签图标回退（16/32/48）
public/apple-touch-icon.png  iOS 主屏图标
scripts/generate-icons.js    由矢量定义重新生成上述位图图标
test/                  Node 自动化测试
```

`npm test` 覆盖网络分组、登录锁定、验证码生命周期、配对与转发、恢复凭证和断线超时。手机 Safari 软键盘等系统行为仍需在真实设备上验证。
